Kết nối Google Sheets một lần — dùng mãi mãi trên mọi thiết bị
1
Tạo Google Sheet mới tại sheets.new → đặt tên Mayo CRM Database
2
Vào Tiện ích mở rộng → Apps Script → dán code Mayo_AppScript.js → chạy setupAllSheets
3
Triển khai → Web app → Mọi người → Deploy → copy URL
URL bắt đầu bằng https://script.google.com/macros/s/ và kết thúc bằng /exec
