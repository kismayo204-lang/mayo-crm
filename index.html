Mayo CRM — Kết nối Google Sheets
Thực hiện 3 bước dưới đây một lần duy nhất. Sau đó dữ liệu sẽ đồng bộ real-time giữa tất cả thiết bị.
1
Tạo Google Sheet mới
Đăng nhập kismayo204@gmail.com → mở sheets.new → đặt tên: Mayo CRM Database → lưu lại.
2
Tạo Apps Script
Trong Sheet vừa tạo: Tiện ích mở rộng → Apps Script → xóa code cũ → dán code từ file Mayo_AppScript.js vào → Lưu → Chạy hàm setupAllSheets → Cấp quyền khi được hỏi.
3
Deploy và lấy URL
Nhấn Triển khai → Triển khai mới → Web app → Ai có quyền truy cập: Mọi người → Triển khai → Copy URL → Dán vào ô bên dưới.
⚠️ URL phải bắt đầu bằng https://script.google.com/macros/s/ và kết thúc bằng /exec. Chỉ cần làm 1 lần, URL được lưu lại tự động.
