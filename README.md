# Mayo Pet Studio Garden — CRM System

Hệ thống quản lí khách hàng, lịch spa, hồ sơ thú cưng.

- **URL:** https://kismayo204-lang.github.io/mayo-crm/
- **Owner:** kismayo204@gmail.com
- **Backend:** Google Sheets via Apps Script

## Cách dùng
Mở URL trên trình duyệt → nhập Apps Script URL → sử dụng bình thường.

## Cập nhật
Mỗi khi có phiên bản mới, chỉ cần **refresh trình duyệt (F5)**.
